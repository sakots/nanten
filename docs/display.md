# 牌とスマートフォンの表示

- 幅820px以下では、手牌を利用可能な幅に合わせて縮小し、横スクロールせずに全牌を表示します。幅320pxの小型画面も対象です。
- 牌の縦横比は42:58を維持します。牌の一部を隠したり、はみ出しを切り取ったりして対処しません。
- 副露は3枚、槓は4枚として幅を割り当てます。副露の区切りとチー・ポン・明槓・暗槓の表示を残します。
- チー・ポンは先頭の1枚を横向きに表示し、出題・回答・振り返りで統一します。横向きの牌の幅も含めて縮小します。鳴いた相手の情報は保持していないため、この位置は相手の方向を表しません。槓の表示は変更しません。
- 和了牌とドラ表示牌は手牌と分けて表示します。回答ボタンなど操作部分は小さくしません。
- 同じ手牌表示を出題中・解説・結果の振り返りで使用します。牌の日本語代替名も維持します。
- PCの通常サイズの牌表示は変更しません。
- 点数のヒント内に「符計算の仕方」を折り畳んで表示します。初期状態は閉じ、ほかの説明と独立して開閉できます。副底・和了方法・面子・雀頭・待ちの加符と、切り上げ・平和・七対子の例外を説明します。
- 「符計算の仕方」と「採用ルールを確認」の間に、「満貫以上の点数計算」と「4翻でも満貫にならない場合」を、この順に折り畳んで表示します。満貫から数え役満までの条件・基本点と、親子・ロン／ツモの支払い倍率を説明します。4翻の20符・25符・30符は満貫未満、40符以上は満貫とし、30符4翻の計算例と25符4翻のロン点、20符4翻のツモ点を示します。3翻60符も切り上げ満貫にしないことを明記します。
- ヒント・回答解説・結果の振り返りでは、符と翻を「60符 3翻」のように符→翻の順で表示します。

## ダークモード

- ヘッダーに「ダークモード」のトグルスイッチを表示します。選択は `localStorage` の `nanten-theme` に `light` または `dark` として保存し、再読み込み・次回アクセス時に復元します。未保存・不正な値・読み取り不可の場合はライトモードで開始します。保存できない場合も、そのページ内での切替は利用できます。
- クリック・Spaceキーで切り替えられ、支援技術にスイッチの名前とオン／オフを伝えます。回答入力・進捗・ヒント・解説の開閉状態は切替でリセットしません。
- 背景・パネル・入力欄・ヒント・解説・結果・更新通知の配色を切り替えます。牌の図柄と色、卓、正誤の判定バナーは維持します。
- 幅320pxでもトグルと遊び方リンクが重ならず、両モードで文字・フォーカス・選択状態を識別できるようにします。


## 理牌と回答の牌姿

- 手牌は雀魂の自動理牌と同じく、萬子→筒子→索子→字牌の順に並べます。数牌は1→9、字牌は東→南→西→北→白→發→中です。同じ牌は隣接させ、メンツ単位の並びや区切りで解答を示しません。
- 和了牌は理牌した手牌に混ぜず、従来どおり別表示します。副露・槓も手牌とは別の組として表示します。
- 回答後の解説と結果の振り返りに「メンツ分け・待ち」を表示します。採用した点数計算に対応する4メンツと雀頭（七対子では7対子）を組ごとに表示し、副露・暗槓も区別します。
- 待ちは両面・嵌張・辺張・シャンポン・単騎の名称と和了前の形、和了牌で示します。メンツ分けでは和了牌1枚を強調します。問題集が採用する解釈を明示するもので、任意の牌姿の自動分解や全待ち牌の列挙は行いません。
- メンツ分けと待ちの図は、出題中と回答前のヒントには表示しません。問題集の全牌姿について、分解の牌と元の手牌・和了牌が一致することを検証します。スマートフォンでは組単位で折り返し、横スクロールを増やしません。

## 確認観点

320px・375px・520px・820px幅で、門前・副露・暗槓・複数副露を含む問題集の全手牌が切れずに収まること、ページ全体にも手牌の列にも横スクロールが不要であることを確認します。結果画面で間違えた問題を開いた際にも同じ条件を満たすことを確認します。

## 正解・不正解の演出

- 回答直後の結果欄を大きな判定バナーとして表示します。正解は深緑と金色、大きな「○」と「正解！」、不正解は赤系の配色、大きな「×」と「不正解」で区別します。色だけで判定を伝えません。
- 正解時は「○」が弾むように拡大し、光の輪と紙吹雪で祝います。不正解時は結果バナーが短く横に揺れ、正しい点数の確認を促します。演出は回答時に一度だけ再生し、連続点滅や無限ループは使いません。
- 演出は結果バナー内に収めます。全画面を覆う表示、音声の自動再生、演出が終わるまで操作を待たせる処理は追加しません。点数・役・符の解説と「次の問題へ」はすぐに利用できます。
- 次の問題へ進むと演出を除去し、次の回答時には再び再生します。既存の判定処理・ヒント利用・回答結果の読み上げは維持します。装飾は読み上げ対象から外します。
- OSの「視差効果を減らす」など `prefers-reduced-motion: reduce` が有効な場合は動きと紙吹雪を止め、配色・大きな記号・判定文だけで結果を示します。
- 回答後の「次の問題へ」（最終問では「結果を見る」）は画面下部に固定し、解説の長さやスクロール位置にかかわらず押せるようにします。回答前・結果画面では表示しません。固定欄はスマートフォンのセーフエリアを避け、ページ末尾に余白を確保して本文やフッターを隠しません。
- 「次の問題へ」では解答欄を自動フォーカスせず、新しい問題の問題番号へフォーカスを移し、その位置を画面上端へ即座にスクロールします。入力欄を開く前に牌姿を確認できるようにし、キーボード操作も問題の先頭から再開します。入力エラー時の解答欄へのフォーカスと、最終問から結果画面へ進む際の結果見出しへのフォーカスは維持します。

### 演出の確認観点

正解・不正解・ヒント利用後の回答、連続して回答したときの演出の再生、演出中の次問操作を確認します。幅320px・390pxとPC幅でバナー・入力した点数・解説が切れずに表示され、横スクロールが発生しないこと、動きを減らす設定ではアニメーションが動かないことを確認します。

回答直後とページ上端・下端で次問ボタンが画面内に収まり、追加のスクロールなしで操作できることを確認します。正解・不正解の両方と最終問の結果遷移、次問・結果画面での固定欄の消去を確認します。

## Android広告あり版

画面下部のバナーはネイティブ側でWebViewとは別領域に表示し、固定の「次の問題へ」「結果を見る」と重ねません。10問終了後の全画面広告、同意確認、フッターの「広告のプライバシー設定」の表示条件は [Android版の広告仕様](android.md#表示とプライバシー) を参照してください。Web版・Android広告なし版には広告領域を設けません。
