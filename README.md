# nanten

牌姿を見て点数を答える、四人リーチ麻雀の点数計算ゲームです。TypeScript・React・Viteで実装しています。

## 遊び方

1. 出題範囲を「すべて」「初級（満貫未満）」「中上級（満貫以上）」から選びます。
2. 手牌、和了牌、場風・自風、ドラ表示牌を見て、支払い点を入力します。
3. 「答え合わせ」で正誤と役・符の内訳を確認し、次の問題へ進みます。困ったら「ヒントを見る」で役と符を確認できます。
4. 全10問を終えると正答率、ヒント利用数、間違えた問題の振り返りを表示します。

## ルール

- 12種類の牌姿を親・子それぞれで練習する全24問（初級12問・中上級12問）から、1回につき重複なしで10問出題します。自由入力の手牌判定機能ではありません。
- ロンは放銃者の支払い、子のツモは子と親それぞれの支払い、親のツモは各子の支払いを回答します。
- 切り上げ満貫なし、数え役満あり。本場・供託は0。赤ドラ・ダブル役満・ローカル役は対象外です。
- 役の翻数はドラを含み、ドラ表示牌はドラそのものではありません。
- 初級は満貫未満、中上級は満貫以上です。ヒント使用でも正解数は減りません。
- 成績は練習中のみ保持します。通信・ログイン・保存データは不要です。

詳細な要件は `openspec/specs/scoring-game/spec.md` に記載しています。

## 開発

Node.js 22.12以上とpnpmを使用します。

```sh
pnpm install
pnpm dev
pnpm test
pnpm build
pnpm preview
```

`pnpm test` は点数計算・問題集・回答判定・練習の状態遷移を検証します。`pnpm build` はTypeScriptの型検査と本番ビルドを実行します。問題集には平和・断么九・役牌・七対子・暗槓・混一色・清一色・三暗刻・大三元を含みます。三倍満・数え役満は点数計算に対応しますが、現在の問題集には含みません。

## 実装方針

資料 → 点数境界・出題・回答のテスト → 最小実装 → 実画面確認の順で開発します。点数計算と問題集をUIから分離し、牌はSVGで描画します。役の自動判定、対局機能、サーバー、永続化は対象外です。
