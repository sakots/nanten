# nanten

牌姿を見て点数を答える、四人リーチ麻雀の点数計算ゲームです。TypeScript・React・Viteで実装しています。

## 遊び方

1. 出題範囲を「すべて」「初級（満貫未満）」「中上級（満貫以上）」から選びます。
2. 手牌、和了牌、場風・自風、ドラ表示牌を見て、支払い点を入力します。
3. 「答え合わせ」で正誤と役・符の内訳を確認し、次の問題へ進みます。困ったら「ヒントを見る」で役と符を確認できます。
4. 全10問を終えると正答率、ヒント利用数、間違えた問題の振り返りを表示します。

## ルール

- 点数計算の採用ルールは、雀魂の四人麻雀・段位戦と同じルールに準拠します。以下の出題範囲は、雀魂の全ルールに対応済みという意味ではありません。
- 12種類の牌姿を親・子それぞれで練習する全24問（初級12問・中上級12問）から、1回につき重複なしで10問出題します。自由入力の手牌判定機能ではありません。
- ロンは放銃者の支払い、子のツモは子と親それぞれの支払い、親のツモは各子の支払いを回答します。
- 切り上げ満貫なし、数え役満あり。現在の出題は本場・供託0に限定し、赤ドラ・ダブル役満などは未対応です。雀魂ではこれらを採用しており、採用ルールと現在の対応状況は下記資料に分けて記載しています。
- 役の翻数はドラを含み、ドラ表示牌はドラそのものではありません。
- 初級は満貫未満、中上級は満貫以上です。ヒント使用でも正解数は減りません。
- 成績は練習中のみ保持します。通信・ログイン・保存データは不要です。

点数計算の採用ルール・符の数え方・計算例は [点数計算のルール](docs/scoring-rules.md) を参照してください。ゲーム全体の要件は `openspec/specs/scoring-game/spec.md` に記載しています。

## スマートフォンにインストール

HTTPSで公開したサイトを開き、AndroidのChromeではメニューの「アプリをインストール」または「ホーム画面に追加」、iPhoneのSafariでは共有メニューの「ホーム画面に追加」を選びます。追加した「nanten」アイコンから独立した画面で起動できます。

初回にオンラインで読み込み、キャッシュの準備が完了した後はオフラインでも練習できます。成績や途中の回答は保存しません。更新は開いているアプリと同サイトのタブをすべて閉じた後に切り替え、練習中に強制リロードしません。詳しくは [PWAの利用・確認手順](docs/deployment.md#7-スマートフォンのpwa) を参照してください。

## 開発

Node.js 22.12以上とpnpmを使用します。

```sh
pnpm install
pnpm dev
pnpm test
pnpm build
pnpm preview
```

`pnpm test` は点数計算・問題集・理牌・回答用のメンツ分解と待ち・回答判定・練習の状態遷移を検証します。`pnpm build` はTypeScriptの型検査と本番ビルドを実行します。問題集には平和・断么九・役牌・七対子・暗槓・混一色・清一色・三暗刻・大三元を含みます。三倍満・数え役満は点数計算に対応しますが、現在の問題集には含みません。

## FTPで公開

`pnpm build` で生成した **`dist/` の中身をすべて**（`index.html`・画像・`assets/`・PWA用のマニフェストとService Workerなど）サーバーの公開ディレクトリへFTPでアップロードしてください。ドメイン直下・`/nanten/` などのサブディレクトリの両方に対応します。公開サーバーにNode.jsやpnpmは不要です。スマートフォンへのPWAインストールにはHTTPSが必要です。

SNSの共有画像を有効にするには、`.env.example` を参考に `.env.local` に `SITE_URL=https://公開先のドメイン/nanten/` を設定してからビルドします。`og:image`・`twitter:image` などに公開先の絶対URLを埋め込みます。URL未設定でもゲームは動作しますが、共有用メタタグは生成しません。

配置例、更新時のアップロード順、確認方法は [FTPによる公開](docs/deployment.md) を参照してください。

## 実装方針

資料 → 点数境界・出題・回答のテスト → 最小実装 → 実画面確認の順で開発します。点数計算と問題集をUIから分離し、牌はSVGで描画します。役の自動判定、対局機能、サーバー、永続化は対象外です。

牌の配色・配置は `images/pai.png` を見本にします。筒子は黒と赤、索子は緑を基調に五索の中央・七索の上段・九索の中央列を赤にします。二索は縦2本、六索は3列2段、七索は上段1本と下段3列2段、八索は左右の縦竹と中央の斜め竹を組み合わせます。一索は緑の尾羽を広げた鳥、白は無地とし、外部画像に依存しないSVGで描画します。
