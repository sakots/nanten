# 点数計算のルール

**nantenの点数計算は、雀魂の四人麻雀・段位戦で使われるルールと同じルールに準拠します。** 友人戦・大会戦の任意設定、三人麻雀、イベント専用ルールは対象にしません。ルールを見直す場合は、この資料を修正し、その内容に合わせて問題集・テスト・実装を更新します。

この資料は「採用するルール」と「現在のゲームで扱える範囲」を区別します。雀魂に存在するルールを未実装だから不採用とはしません。現時点の実装が雀魂の全機能に対応しているという意味ではありません。出典は末尾に記載します。

## 1. 採用ルールと対象範囲

- 親は自風が東のプレイヤー、残る3人は子です。
- ロンは放銃者1人、ツモは和了者以外の3人が支払います。
- 喰いタン・後付けあり。副露した手でも断么九が成立します。ドラ以外の役が最低1翻必要で、2翻縛りはありません。
- 切り上げ満貫なし。3翻60符・4翻30符は満貫にしません。
- 数え役満あり。通常役とドラの合計が13翻以上なら、単一役満と同じ点数にします。
- 赤ドラは五萬・五筒・五索に各1枚、計3枚。裏ドラ・槓ドラ・槓裏ドラあり。
- ダブル役満あり。国士無双十三面待ち・四暗刻単騎・大四喜・純正九蓮宝燈は2倍の役満とします。複合する役満は倍率を加算します。
- 本場は1本につきロンで300点、ツモで各支払い者に100点を加算します。供託のリーチ棒は1本1,000点で、和了点とは別に和了者が受け取ります。
- 大三元・大四喜に包（責任払い）あり。大明槓そのものの責任払いはありません。詳細は第6節を参照してください。
- ローカル役は不採用。流し満貫は採用しますが、通常の牌姿からの和了とは別の流局時精算です。

### 現在の練習範囲

- 本場・供託は0の問題だけを出題します。
- 赤ドラ・裏ドラ・槓裏ドラ、ダブル役満・複合役満、包、流し満貫は現在の問題集では扱いません。
- 現在の問題集は各問に登録されたドラ表示牌だけを表示します。暗槓を含む問題もありますが、槓に伴う追加表示牌の扱いは雀魂と同じ状態を完全には再現していません。
- 以上は実装・出題範囲の制限であり、雀魂準拠の採用ルールを変更するものではありません。

現在は、役・翻・符の内訳をあらかじめ確定した問題集形式です。自由入力の手牌から役や符を自動判定する機能ではありません。以下の符・役の説明は問題を作成・確認する際の基準でもあり、すべてを自動判定器として実装しているわけではありません。

## 2. 計算の順序

1. 成立する役と副露による翻数の変化を確認します。
2. ドラを加えて合計翻数を求めます。役満の場合は通常役・ドラを加算しません。
3. 面子、雀頭、待ち、和了方法から符を求めます。
4. 翻・符から基本点を求め、満貫以上の上限を適用します。
5. 親子・ロン／ツモに応じた倍率を基本点に掛けます。
6. **支払う人ごとに100点単位で切り上げます。**

翻は役の価値、符は手の構成に付く点です。支払い額と「基本点」は別の値です。

## 3. 翻と役

### 現在の問題集で使用する役

| 役 | 門前 | 副露あり | 主な条件・注意 |
| --- | --- | --- | --- |
| 平和 | 1翻 | 不成立 | 4順子、役牌でない雀頭、両面待ち |
| 門前清自摸和 | 1翻 | 不成立 | 門前の手をツモ和了。暗槓だけなら門前を維持 |
| 断么九 | 1翻 | 1翻 | 2〜8の数牌だけで構成 |
| 役牌 | 1組につき1翻 | 1組につき1翻 | 白・發・中、場風、自風の刻子または槓子。連風牌は場風・自風を両方数える |
| 七対子 | 2翻 | 不成立 | 異なる7種類の対子。同じ牌4枚を2対子とは扱わない |
| 対々和 | 2翻 | 2翻 | 4面子がすべて刻子または槓子 |
| 三暗刻 | 2翻 | 2翻 | 暗刻・暗槓が合計3組。ロン牌で完成した刻子は暗刻に数えない |
| 一盃口 | 1翻 | 不成立 | 同じ順子2組。二盃口とは複合しない |
| 二盃口 | 3翻 | 不成立 | 同じ順子2組の組み合わせが2つ。七対子とは複合しない |
| 三色同順 | 2翻 | 1翻 | 萬子・筒子・索子で同じ数字の順子 |
| 混全帯么九 | 2翻 | 1翻 | すべての面子と雀頭に么九牌を含み、順子と字牌を使う |
| 純全帯么九 | 3翻 | 2翻 | すべての面子と雀頭に老頭牌を含み、順子を使い、字牌を使わない |
| 混老頭 | 2翻 | 2翻 | 老頭牌と字牌だけ。七対子または対々和と複合する |
| 小三元 | 2翻 | 2翻 | 三元牌2種類の刻子・槓子と、残る三元牌の雀頭。役牌の翻も数える |
| 一気通貫 | 2翻 | 1翻 | 同じ種類の数牌で123・456・789の順子 |
| 混一色 | 3翻 | 2翻 | 1種類の数牌と字牌で構成 |
| 清一色 | 6翻 | 5翻 | 1種類の数牌だけで構成 |
| 大三元 | 役満 | 役満 | 白・發・中がすべて刻子または槓子 |

成立条件を満たす役は複合させます。ただし、役満には通常役やドラを加算しません。この表は全役の一覧ではなく、現在の問題集で使用している役の一覧です。立直・一発など、牌姿だけでは分からない追加状況を必要とする問題は現在ありません。

### ドラ

- ドラ1枚につき1翻を加えます。槓子の4枚もそれぞれ数えます。
- ドラだけでは役になりません。和了にはドラ以外の役が必要です。
- 表示されるのは「ドラ表示牌」であり、実際のドラは次の牌です。
- 萬子・筒子・索子はそれぞれ `1 → 2 → … → 9 → 1` と循環します。
- 風牌は `東 → 南 → 西 → 北 → 東` と循環します。
- 三元牌は `白 → 發 → 中 → 白` と循環します。

例：七索表示なら八索、西表示なら北、中表示なら白がドラです。

- 赤五は通常の五として面子を構成し、赤ドラとして1翻を加えます。表示牌によるドラと重なれば両方を数えます。
- 裏ドラ・槓裏ドラは立直して和了した場合だけ数えます。
- 槓ドラは暗槓では即時に公開し、大明槓・加槓では打牌後、または続く槓の直前に公開します。
- 現在の出題では登録された表示牌だけを使います。未表示の裏ドラや追加の槓ドラを回答者が推測して加える必要はありません。

## 4. 符の数え方

### 基本と加符

原則として、副底20符に以下の符を加え、合計を10符単位で切り上げます。例外は後述の平和ツモと七対子です。

| 項目 | 符 | 条件 |
| --- | --- | --- |
| 副底 | 20符 | 通常の手の基本符 |
| 門前ロン | ＋10符 | 門前でロン和了 |
| ツモ | ＋2符 | 平和ツモを除く。副露した手にも付く |
| 数牌2〜8の明刻 | ＋2符 | ポン、またはロン牌で完成した刻子 |
| 么九牌の明刻 | ＋4符 | 1・9・字牌の明刻 |
| 数牌2〜8の暗刻 | ＋4符 | 手牌の中で完成。ツモ牌で完成した刻子も含む |
| 么九牌の暗刻 | ＋8符 | 1・9・字牌の暗刻 |
| 数牌2〜8の明槓 | ＋8符 | 副露した槓子 |
| 么九牌の明槓 | ＋16符 | 1・9・字牌の明槓 |
| 数牌2〜8の暗槓 | ＋16符 | 暗槓 |
| 么九牌の暗槓 | ＋32符 | 1・9・字牌の暗槓 |
| 役牌の雀頭 | ＋2符 | 白・發・中、場風、自風の対子 |
| 連風牌の雀頭 | ＋4符 | 場風と自風が同じ牌の対子。2符ずつを合計 |
| 嵌張待ち | ＋2符 | 例：24に3で和了 |
| 辺張待ち | ＋2符 | 例：12に3、89に7で和了 |
| 単騎待ち | ＋2符 | 雀頭を完成させる待ち |

- 順子、役牌でない雀頭、両面待ち、双碰待ち自体には符が付きません。
- 双碰待ちでロンした場合、完成した刻子は明刻として計算します。ただし、それだけで手全体が副露扱いになるわけではなく、門前ロンの10符は付きます。
- 待ち符は和了した形に対して数えます。複数の分解が可能な場合は、成立する役・符を含め、和了点が最も高くなる解釈を採用します。
- 24符なら30符、32符なら40符、54符なら60符です。すでに30符・40符などなら、そのままです。
- 嶺上開花のツモにも通常どおり2符を加えます。

### 特例

| 手 | 扱い |
| --- | --- |
| 平和ツモ | 20符固定。ツモの2符を加えない |
| 平和ロン | 副底20符＋門前ロン10符＝30符 |
| 七対子 | 25符固定。門前ロン・ツモ・雀頭・待ちの符を加えず、30符にも切り上げない |
| 副露した平和形のロン | 加符がなくても最低30符。役としての平和は付かず、別の役が必要 |

七対子の門前ツモには、役としての門前清自摸和1翻は付きます。「ツモの2符を付けない」こととは別です。

## 5. 基本点と満貫以上

満貫未満の基本点は、次の式で求めます。

`基本点 ＝ 符 × 2^(翻＋2)`

| 区分 | 条件 | 基本点 |
| --- | --- | ---: |
| 満貫未満 | 下記の条件に達しない手 | 上の式で計算 |
| 満貫 | 5翻、または4翻40符以上、または3翻70符以上 | 2,000 |
| 跳満 | 6〜7翻 | 3,000 |
| 倍満 | 8〜10翻 | 4,000 |
| 三倍満 | 11〜12翻 | 6,000 |
| 数え役満 | 通常役・ドラで13翻以上 | 8,000 |
| 単一役満 | 大三元など、倍率1の役満役 | 8,000 |

5翻未満でも式の結果が2,000以上なら満貫にします。数え役満は13翻以上でも単一役満の基本点8,000が上限です。一方、役満役のダブル役満・複合役満は加算し、役満倍率をnとすると基本点は `8,000 × n` です。たとえば四暗刻単騎は2倍、大四喜と字一色の複合は3倍の役満です。数え役満と役満役をさらに足し合わせることはしません。

現在の計算関数は基本点8,000までで、ダブル役満・複合役満には未対応です。画面上では数え役満も「役満」と表示します。大三元は問題データ上で13翻相当として保持しますが、通常役を足して成立する数え役満とは区別します。

**切り上げ満貫は採用しません。** 3翻60符・4翻30符はどちらも基本点1,920です。子のロンは7,700点、親のロンは11,600点になります。

4翻でも20符・25符・30符は満貫未満で、40符以上から満貫になります。25符4翻のロンは子6,400点・親9,600点です。20符は平和ツモだけで、20符4翻では子のツモが子1,300点・親2,600点、親のツモが各子2,600点です。20符のロンはありません。

## 6. 親子・和了方法による支払い

| 和了者・方法 | 支払う人 | 支払い額（各人） |
| --- | --- | --- |
| 子のロン | 放銃者1人 | 基本点×4を100点単位で切り上げ |
| 親のロン | 放銃者1人 | 基本点×6を100点単位で切り上げ |
| 子のツモ | 子2人 | それぞれ基本点×1を100点単位で切り上げ |
| 子のツモ | 親1人 | 基本点×2を100点単位で切り上げ |
| 親のツモ | 子3人 | それぞれ基本点×2を100点単位で切り上げ |

ツモは支払いを個別に切り上げた後で合計します。ロンとツモで和了者の受取合計が一致しないことがあります。

### 満貫以上の支払い早見表

ツモの「子／親」は、子1人あたりの支払い／親の支払いです。

| 区分 | 子のロン | 子のツモ（子／親） | 親のロン | 親のツモ（各子） |
| --- | ---: | ---: | ---: | ---: |
| 満貫 | 8,000 | 2,000／4,000 | 12,000 | 4,000 |
| 跳満 | 12,000 | 3,000／6,000 | 18,000 | 6,000 |
| 倍満 | 16,000 | 4,000／8,000 | 24,000 | 8,000 |
| 三倍満 | 24,000 | 6,000／12,000 | 36,000 | 12,000 |
| 役満・数え役満 | 32,000 | 8,000／16,000 | 48,000 | 16,000 |

ダブル役満・複合役満は、この表の役満の支払いを役満倍率倍にします。本場・供託は役満倍率で増やしません。

### 本場・供託と複数ロン

- 上記の支払い額を切り上げた後に、本場分を加算します。
- リーチ棒の供託は支払い額の倍率計算には含めず、別途和了者に渡します。
- ダブロン・トリプルロンあり。同時和了では本場・供託は放銃者から見てツモ順が最も近い和了者（上家取り）が受け取ります。
- 現在のゲームは0本場・供託なし・和了者1人に限定しているため、これらの精算は回答しません。

### 包（責任払い）

- 大三元・大四喜を確定させる副露をさせたプレイヤーに、対応する役満分の責任払いを適用します。
- ツモでは包の対象となる役満分を責任者が全額支払います。
- ロンで責任者と放銃者が別人なら、対象となる役満分を2人で折半します。同一人物ならその人が全額支払います。
- 複合役満では包が適用される役満分だけを責任払いとし、残りは通常どおり精算します。
- 積み棒は責任者の負担です。現在の問題集は責任払いの発生する副露経緯を設定していないため、通常のロン／ツモとして回答します。

## 7. 計算例

### 子の平和ロン：1翻30符

- 平和1翻、副底20符＋門前ロン10符＝30符。
- 基本点：`30 × 2^(1＋2) ＝ 240`。
- 放銃者の支払い：`240 × 4 ＝ 960` を切り上げて **1,000点**。

### 子の平和ツモ：2翻20符

- 平和1翻＋門前清自摸和1翻、20符固定。
- 基本点：`20 × 2^(2＋2) ＝ 320`。
- 子2人はそれぞれ320を切り上げて **400点**、親は640を切り上げて **700点**。
- 受取合計：`400 × 2 ＋ 700 ＝ 1,500点`。

### 子の七対子ロン：2翻25符

- 七対子2翻、25符固定。
- 基本点：`25 × 2^(2＋2) ＝ 400`。
- 放銃者の支払い：`400 × 4 ＝ 1,600点`。

### 親の暗槓を含むツモ：3翻60符

- 白1翻＋門前清自摸和1翻＋ドラ1翻。
- 副底20符＋白の暗槓32符＋ツモ2符＝54符を60符へ切り上げ。
- 基本点：`60 × 2^(3＋2) ＝ 1,920`。切り上げ満貫にしない。
- 子3人がそれぞれ `1,920 × 2 ＝ 3,840` を切り上げて **3,900点**。
- 受取合計：`3,900 × 3 ＝ 11,700点`。

## 8. ゲームで入力する点数

- ロン：放銃者1人の支払い点を入力します。
- 子のツモ：子1人あたりの支払い点と親の支払い点を、それぞれの欄に入力します。
- 親のツモ：子1人あたりの支払い点を入力します。
- ツモの受取合計を入力するのではありません。
- 回答欄は正の整数とし、すべての支払いが正解と一致した場合のみ、その問題を正解にします。
- ヒントを使っても点数計算や正誤判定は変わりません。

## 9. 実装との対応

- `src/game/scoring.ts`：合計翻・符から基本点・支払い額を計算し、回答を判定。
- `src/game/problems.ts`：牌姿、成立役、ドラ表示牌、翻・符とその内訳を保持。
- `src/game/scoring.test.ts`：点数境界、切り上げ、親子の支払いなどを検証。
- `src/game/problems.test.ts`：問題の牌構成、翻・符の整合性などを検証。
- `openspec/specs/scoring-game/spec.md`：ゲーム全体の要件。

出題範囲は初級（満貫未満）、中級（満貫〜倍満・通常の役満）、上級（三倍満・数え役満）です。通常の役満は翻の足し算が不要なので中級に含め、上級では通常役とドラを合計する11〜13翻の問題を扱います。v0.8.4では35種類・親子合計70問（初級24問・中級24問・上級22問）を用意します。嵌張・辺張・シャンポン・単騎、役牌の雀頭、明槓・暗槓、食い下がり、順子系と刻子系の役の複合を扱います。一局内では親子やロン／ツモだけが違う同じ牌姿を重ねず、異なる10問を出題します。役・符の採用ルールを変更する場合は、計算関数だけでなく問題データと解説にも反映します。

### 雀魂ルールに対する現在の対応状況

| 項目 | 採用する雀魂ルール | 現在のゲーム |
| --- | --- | --- |
| 連風牌の雀頭 | 4符 | 資料の規定は一致。現在の出題には該当例なし |
| 切り上げ満貫 | なし | 対応済み |
| 数え役満 | 13翻以上で単一役満 | 計算・上級の出題に対応済み |
| ダブル役満・役満複合 | あり | 計算関数の基本点8,000上限では未対応 |
| 赤ドラ・裏ドラ・槓裏ドラ | あり | 未出題 |
| 槓ドラの追加・公開時機 | 暗槓は即乗り、明槓・加槓は後めくり | 追加表示牌と公開時機の再現は未対応 |
| 本場・供託 | 加算・受渡しあり | 0に固定 |
| 包・複数ロン・流し満貫 | あり | 未出題・未対応 |

雀魂準拠の仕様と現在の実装には上記の差があります。対応範囲を広げる際は、この資料の採用ルールに合わせて実装・問題集・テストを更新します。今回の資料改訂だけで、これらが実装済みになったとは扱いません。
