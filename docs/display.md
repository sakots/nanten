# 牌とスマートフォンの表示

- 幅820px以下では、手牌を利用可能な幅に合わせて縮小し、横スクロールせずに全牌を表示します。幅320pxの小型画面も対象です。
- 牌の縦横比は42:58を維持します。牌の一部を隠したり、はみ出しを切り取ったりして対処しません。
- 副露は3枚、槓は4枚として幅を割り当てます。副露の区切りとチー・ポン・明槓・暗槓の表示を残します。
- 和了牌とドラ表示牌は手牌と分けて表示します。回答ボタンなど操作部分は小さくしません。
- 同じ手牌表示を出題中・解説・結果の振り返りで使用します。牌の日本語代替名も維持します。
- PCの通常サイズの牌表示は変更しません。

## 確認観点

320px・375px・520px・820px幅で、門前・副露・暗槓・複数副露を含む問題集の全手牌が切れずに収まること、ページ全体にも手牌の列にも横スクロールが不要であることを確認します。結果画面で間違えた問題を開いた際にも同じ条件を満たすことを確認します。

## 正解・不正解の演出

- 回答直後の結果欄を大きな判定バナーとして表示します。正解は深緑と金色、大きな「○」と「正解！」、不正解は赤系の配色、大きな「×」と「不正解」で区別します。色だけで判定を伝えません。
- 正解時は「○」が弾むように拡大し、光の輪と紙吹雪で祝います。不正解時は結果バナーが短く横に揺れ、正しい点数の確認を促します。演出は回答時に一度だけ再生し、連続点滅や無限ループは使いません。
- 演出は結果バナー内に収めます。全画面を覆う表示、音声の自動再生、演出が終わるまで操作を待たせる処理は追加しません。点数・役・符の解説と「次の問題へ」はすぐに利用できます。
- 次の問題へ進むと演出を除去し、次の回答時には再び再生します。既存の判定処理・ヒント利用・フォーカス移動・回答結果の読み上げは維持します。装飾は読み上げ対象から外します。
- OSの「視差効果を減らす」など `prefers-reduced-motion: reduce` が有効な場合は動きと紙吹雪を止め、配色・大きな記号・判定文だけで結果を示します。

### 演出の確認観点

正解・不正解・ヒント利用後の回答、連続して回答したときの演出の再生、演出中の次問操作を確認します。幅320px・390pxとPC幅でバナー・入力した点数・解説が切れずに表示され、横スクロールが発生しないこと、動きを減らす設定ではアニメーションが動かないことを確認します。
